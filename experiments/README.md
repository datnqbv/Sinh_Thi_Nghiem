# Thí nghiệm Sinh học

Thư mục này chỉ chứa các thí nghiệm Sinh học tương tác. Bài học lý thuyết đặt trong `modules/`; file mẹ nhúng nội dung đặt trong `shells/`.

## Cấu trúc

```text
experiments/
├── Lop_10/
├── Lop_11/
└── Lop_12/
```

Mỗi thí nghiệm được đóng gói độc lập:

```text
<MA_THI_NGHIEM>/
├── <HTML_THI_NGHIEM>.html
├── <TEN_GOC_KICH_BAN_NOI_DUNG>.txt
├── <TEN_GOC_KICH_BAN_TAO_ANH>.md
└── images/
```

Giữ nguyên tên gốc của hai file kịch bản. Một thí nghiệm được phép có nhiều HTML nếu kịch bản chia thành nhiều phần.
