# Module Sinh học lớp 12

Mỗi module lớp 12 đặt trong một thư mục có tên theo mẫu:

```text
SH12_Bxx_Mxx/
├── SH12_Bxx_Mxx.html
├── <TEN_GOC_KICH_BAN_NOI_DUNG>.txt
├── <TEN_GOC_KICH_BAN_TAO_ANH>.md
└── images/
```

Giữ nguyên tên hai file kịch bản khi đưa chúng vào thư mục module. Trước khi tạo module mới, đọc `AGENTS.md` và hai file rule ở thư mục gốc.
